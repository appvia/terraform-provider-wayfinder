# wayfinder_stack (Data Source)

Stack is a named, deployable unit of application and infrastructure within a workspace, and the lasting identity that every deployment of it belongs to. The stack's contents — its components, variables and secrets — are described in a Wayfinder.yaml, which can be held in an associated code repository. Deploying that definition into an environment with `wf deploy` or `wf up` produces a StackInstance; the Stack itself carries the name, description and repository the deployments share.
