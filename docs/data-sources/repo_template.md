# wayfinder_repo_template (Data Source)

RepoTemplate registers an upstream repository as a scaffolding template. The template's definition — name, description, language, inputs and skeleton location — lives inside the template repository as a wayfinder-template.yaml manifest, so a template is versioned together with its content. Wayfinder keeps a copy of that manifest, refreshed from the source, for catalogue listings and input forms; scaffolding renders the skeleton tree with a user's inputs and pushes the result as the initial commit of a newly-created repository.

The source is either a CodeRepo (private repositories, accessed through the GitHub App) or a public https git URL (community templates, read anonymously). Exactly one must be set.
