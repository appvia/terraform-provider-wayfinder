# wayfinder_cloud_resource_plan (Data Source)

CloudResourcePlan is a reusable, versioned Terraform/OpenTofu template that developers can provision cloud resources from without writing Terraform themselves. It provisions either infrastructure — a database, a storage bucket, a network — or an application runtime such as Cloud Run, Lambda or Azure Container Apps.

A plan declares the inputs it accepts and the outputs it produces, the Terraform files and modules that build the resource, and optionally a workload identity for applications to assume along with the named sets of permissions ("consumption policies") that identity can be granted. Published to the catalogue, it becomes a self-service option: each deployment of it is a CloudResource.

Plans are versioned, so a new version can be published without disturbing resources already provisioned from an earlier one, and can be defined by Wayfinder, by a tenant for all its workspaces, or by a single workspace.

## Example Usage

```terraform
// Code generated by tfgen. DO NOT EDIT.
data "wayfinder_cloud_resource_plan" "example" {
  name = "example"
  workspace = "example"
  version = "1.0.0"
}
```
