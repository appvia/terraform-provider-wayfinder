# wayfinder_repository (Data Source)

Repository is a Helm chart repository that kube resource plans can pull charts from, either an HTTP chart repository or an OCI registry. It records the repository URL, any credentials needed to authenticate to it and any private certificate authority needed to trust it, and lists the charts and versions Wayfinder found there so they can be browsed when building a plan.
