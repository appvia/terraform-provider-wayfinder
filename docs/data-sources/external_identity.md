# wayfinder_external_identity (Data Source)

ExternalIdentity represents credentials or configuration that grant Wayfinder access to an external system: a cloud account (an AWS account, Azure subscription, or GCP project), a source control provider, a container registry, or any other endpoint Wayfinder must authenticate to on your behalf. The type field selects what kind of access this is and, for cloud types, which cloud it reaches; the matching sub-block carries the identity's configuration and any secret material.

## Example Usage

```terraform
// Code generated by tfgen. DO NOT EDIT.
data "wayfinder_external_identity" "example" {
  name = "example"
  workspace = "example"
}
```
