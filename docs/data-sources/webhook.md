# wayfinder_webhook (Data Source)

Webhook accepts signed HTTP POST deliveries from an external system at a secret ingest URL, and writes data extracted from each delivery onto the Wayfinder resources it matches. The signature, target-resource query and the values to store are all configured on the spec; every delivery is recorded as a WebhookInvocation.

## Example Usage

```terraform

  name = "example"
  workspace = "example"
}
```

<a id="nestedatt--security"></a>
### Nested Schema for `security`

Read-Only:

- `algorithm` (String) Algorithm is the HMAC algorithm the upstream uses to sign the body. "none" means URL secrecy only — accepted but not recommended for any payload an attacker could mint.

- `hmac-sha256`: Verifies deliveries with an HMAC-SHA256 signature of the request body (e.g. GitHub's X-Hub-Signature-256).

- `hmac-sha1`: Verifies deliveries with an HMAC-SHA1 signature of the request body.

- `none`: Performs no signature verification, relying on the secrecy of the ingest URL alone. Not recommended for any payload an attacker could mint.
- `request_id_header` (String) RequestIDHeader is the upstream's per-delivery unique ID header (e.g. X-GitHub-Delivery). Enables short-window dedup.
- `signature_header` (String) SignatureHeader is the HTTP header the upstream uses to carry the signature (e.g. "X-Hub-Signature-256"). Required unless Algorithm is "none".
- `signature_prefix` (String) SignaturePrefix is stripped from the header value before comparison (e.g. "sha256=" for GitHub).

<a id="nestedatt--storage--data"></a>
### Nested Schema for `storage.data`

Read-Only:

- `data_type` (String) DataType references the DataType resource whose schema validates the mapped Values. Its name — without any workspace prefix — is the key the data is stored under on the target resource. A bare name is the tenant's shared type, e.g. "incident"; "workspace/name" is one that workspace defined for itself, e.g. "team-a/incident". There is no fallback between the two, so a bare name always means the shared type. Only this webhook's own workspace may be named: a tenant-scoped webhook can use the shared types alone, and no webhook can reach into another workspace. When set, Values must also be set (typed mode). When unset, the webhook runs in raw mode: the inbound body is stored verbatim under dataKey=<webhook name> with no schema check and no JQ extraction.
- `keep_history` (Boolean) KeepHistory controls write semantics. false (default) means each delivery overwrites the entry in place. true increments the generation and retains prior values as an audit trail.
- `values` (Map of String) Values is a map of stored-field name → JQ expression, e.g. {"severity": ".body.status"}. Each expression is evaluated against the delivery to build the object that is stored. Required when DataType is set; must be empty when DataType is empty.

### Nested Schema for `storage.resource`

Read-Only:

- `environment` (String) Environment is a JQ expression over the payload yielding the environment to match, e.g. `.body.labels.environment`. Omit to match any environment.
- `kind` (List of String) Kind is the Wayfinder kind(s) to match — accepts a single kind name (`kind: StackInstance`) or a list of kinds (`kind: [StackInstance, KubeResource]`) to broadcast across kinds. Required once a data mapping is configured (enforced by validation); an endpoint-only webhook has no mapping.
- `labels` (Map of String) Labels is a map of label key → JQ expression, e.g. {"team": ".body.commonLabels.team"}. Each entry adds a label the target resource must carry with the resulting value.

- `on_multi_match` (String) OnMultiMatch controls behaviour when the query returns >1 match. "all" (default) writes to every match; "first" picks the alphabetically first.

- `first`: Writes only to the alphabetically first match.
- `workspace` (String) Workspace is a JQ expression over the payload yielding the workspace to match, e.g. `.body.labels.workspace`. Omit to match any workspace.
