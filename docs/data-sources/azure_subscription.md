# wayfinder_azure_subscription (Data Source)

AzureSubscription is an Azure subscription your tenant works in. You add one for each subscription you operate, which is what tells Wayfinder the subscription exists before any credential for it does — so you can see and pick it while setting the rest up.

Its name is the subscription ID, e.g. "00000000-0000-0000-0000-000000000000", so a subscription is the same object however it is reached and a reference to it can never come to mean a different real subscription. Give it a display name to say what it is for.

It grants no access of its own: an external identity naming this subscription is what lets Wayfinder act in it. It records only facts about the subscription and never changes state, so it has no status.
