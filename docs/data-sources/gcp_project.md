# wayfinder_gcp_project (Data Source)

GCPProject is a Google Cloud project your tenant works in. You add one for each project you operate, which is what tells Wayfinder the project exists before any credential for it does — so you can see and pick it while setting the rest up.

Its name is the project ID, e.g. "example-project", so a project is the same object however it is reached and a reference to it can never come to mean a different real project. Give it a display name to say what it is for.

It grants no access of its own: an external identity naming this project is what lets Wayfinder act in it. It records only facts about the project and never changes state, so it has no status.
