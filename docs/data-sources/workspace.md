# wayfinder_workspace (Data Source)

Workspace is a team's or project's own area within a tenant, and the main unit of isolation below the tenant itself. It owns the resources created in it, holds the environments those resources are deployed into, and is the level most access is granted at - so one team's workspace stays separate from another's.
