# wayfinder_cluster (Data Source)

Cluster represents a Kubernetes cluster (EKS, AKS, or GKE) that Wayfinder manages as a deployment target for workloads. It records where the cluster lives — the cloud account, region and provider-specific details — which of the cluster's existing ClusterRoles Wayfinder users and deployments may be granted, and whether namespaces are created on demand for the workspaces that share it. Its status reports what Wayfinder can see of the cluster: its health, the connectivity and version of the Wayfinder agent running inside it, and the endpoint used to reach its Kubernetes API.

Clusters can be shared beyond the workspace that owns them; use scope to control which workspaces may deploy to this one.

Read-Only:

Leave it empty to require the role at workspace scope and nothing narrower, or set "*" to match the role held at workspace scope or in any one environment.
