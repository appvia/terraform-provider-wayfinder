# wayfinder_github_org (Data Source)

GitHubOrg is a connection between Wayfinder and a GitHub organization, established by installing the Wayfinder GitHub App into that organization. The connection lets Wayfinder read and raise changes against the repositories the organization has shared with the App, and it lists those repositories in its status so you can see exactly what Wayfinder can reach. Register an individual repository as a CodeRepo to refer to it elsewhere in Wayfinder. A GitHubOrg is held at tenant level and can be used by every workspace in the tenant.
