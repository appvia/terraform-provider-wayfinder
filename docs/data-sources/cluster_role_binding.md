# wayfinder_cluster_role_binding (Data Source)

ClusterRoleBinding grants a Wayfinder user or service account one of the Kubernetes ClusterRoles a cluster makes available, either across the whole cluster or within a single namespace, and optionally only until an expiry time. Wayfinder creates the corresponding Kubernetes binding in the cluster and removes it again when the grant is deleted or expires.

Bindings are normally created for you by `wf access cluster` and `wf access namespace`; the role requested must be one the cluster offers in its access rules, and you must be among the subjects that rule allows.
