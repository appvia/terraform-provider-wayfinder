# wayfinder_cloud_resource_state_store (Data Source)

CloudResourceStateStore says where the state that Wayfinder keeps for cloud resources is stored in your own cloud. Every cloud resource is provisioned through Terraform/OpenTofu, which records what it created in a state file; this resource names the bucket, container or storage account those files live in, either as a naming convention per cloud that covers every account in it or as an explicit location for a particular destination.

A resource's state is kept in the cloud it deploys to, so a tenant using more than one cloud gives a convention for each: state for an AWS account goes to the Amazon S3 convention, state for an Azure subscription to the Azure one, and so on.

It is set at tenant, workspace or environment level, under the well-known name "default". The nearest one wins and is merged field by field over the levels above it, so a team can adjust a single field — for example a prefix — without restating the whole configuration. What a lower level is allowed to change is controlled by the override policy on the tenant-level resource.

Changing this configuration only affects cloud resources created afterwards: each resource remembers the location it was first given, so existing state is never moved or lost.
