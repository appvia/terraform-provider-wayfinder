# wayfinder_data_type (Data Source)

DataType describes the shape of data returned by an integration, as a JSON Schema that the response is validated against before it is stored, plus the fields within it that should be searchable. Data types are entirely optional - a response with no data type named for it is stored as-is, without validation.
