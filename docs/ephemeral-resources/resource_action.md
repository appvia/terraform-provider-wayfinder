# wayfinder_resource_action (Ephemeral Resource)

For a webhook's ingest URL use [`wayfinder_webhook_ingest_url`](webhook_ingest_url.md). It's typed and needs no Wayfinder API names.

Reads a Wayfinder object sub-resource using GET on every plan and apply. For a webhook's ingest URL use `wayfinder_webhook_ingest_url`. The sensitive output is ephemeral and is never stored in state or plan files. Requires Terraform/OpenTofu >= 1.11.

This resource reads one sub-resource of a Wayfinder object with a GET request and returns the response in `output`. Name the object with `type` (`group/version/Kind`, for example `integrations/v3/Webhook`), `name`, and `workspace` and `environment` where the kind needs them. `action` is the sub-resource to read. Set `response_export_values` to a list of dot-separated paths into the JSON object response, for example `["url"]` or `["status.token"]`. When set, `output` contains only those paths with their nesting preserved, and a missing path appears as null. The whole of `output` is sensitive.

## Requirements and lifecycle

This is an ephemeral resource, so it needs Terraform 1.11 or later, or OpenTofu 1.11 or later. It's read on every plan and apply and is never stored in state or plan files. Use its result only where ephemeral values are allowed: write-only attributes such as `value_wo`, provider blocks, locals and other ephemeral resources.

## Example Usage

```terraform
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: Apache-2.0

# Read a sub-resource of any Wayfinder object. This reads a webhook's
# ingest URL, which wayfinder_webhook_ingest_url also covers.
ephemeral "wayfinder_resource_action" "alerts_ingest_url" {
  type                   = "integrations/v3/Webhook"
  name                   = "alerts"
  workspace              = "plat"
  action                 = "ingesturl"
  response_export_values = ["url"]
}

# output is sensitive and ephemeral, so feed it to a write-only attribute.
resource "wayfinder_secret" "alerts_ingest_url" {
  key              = "alerts_ingest_url"
  value_wo         = jsonencode(ephemeral.wayfinder_resource_action.alerts_ingest_url.output.url)
  value_wo_version = "1"
}
```
