# wayfinder_mcp (Resource)

MCP is a registration of a Model Context Protocol server that makes the server's tools available to AI agents in your tenant. Wayfinder contacts the server to discover its tools, which are then offered to each AI agent the MCP is bound to. Each tool is exposed as mcp__<name>__<remote-tool-name>. Wayfinder also ships its own built-in MCP registrations alongside the ones you create.

### Nested Schema for `spec_connection`

Optional:

- `auth` (Attributes) Auth is the credential presented on each request. Leave it unset for a service that needs none. (see [below for nested schema](#nestedatt--spec_connection--auth))
- `base_url` (String) BaseURL is the address requests are sent to, e.g. "https://api.example.com". It carries the scheme and host; what follows is the caller's — a WebAPI appends each operation's path, an MCP appends its own spec.path.

It may be a literal, or an expression over the inputs the object declares, e.g. "https://api.${{ .Inputs.site }}". An expression lets one shipped definition serve every tenant, each supplying its own value.

Required before the object may be enabled; one you have not finished configuring may leave it blank until then.
- `headers` (Map of String) Headers are sent on every request, in addition to anything an individual operation adds. Values may be literals or expressions over the declared inputs. Do not set a credential header here — Auth applies the credential by its type, and a header set by hand bypasses that.

On an MCP a value may also read the arguments of the tool call it is sent with, as "${{ .Args.<name> }}", so one registration serves every repository or project an agent asks about instead of one per value. GitHub's hosted Actions server wants "Mcp-Param-owner" and "Mcp-Param-repo" that way: with "${{ .Args.owner }}" the agent passes owner and repo in the tool call, as the tool's own schema asks, and the call works. A header reading an argument the call did not carry is left off, so the server answers saying which value it wanted rather than acting on a blank one. A WebAPI has no such arguments and refuses the expression.
