# wayfinder_service_account_credential (Resource)

ServiceAccountCredential is a single way for a service account to authenticate to Wayfinder. A service account can have several credentials at once, allowing new credentials to be issued and old ones removed without interrupting automation. Deleting a credential immediately revokes it.

## Example Usage

```terraform
resource "wayfinder_service_account_credential" "example" {
  name = "example"
  workspace = "example"
  method = "Token"
  service_account = "example"
}
```

## Schema

### Required

- `method` (String) Method is how this credential authenticates: "Token" for a Wayfinder-issued secret token, or "Federated" for an inbound OIDC trust described by the federated block.

- `Token`: Authenticates with a Wayfinder-issued secret token. The token is returned once when the credential is created and remains valid until the credential is deleted or its expiry passes.

- `Federated`: Authenticates by exchanging a short-lived OIDC identity token from a trusted external issuer (for example GitHub Actions or another cloud) for a Wayfinder API token. No secret is stored: the trust is described entirely by the federated block.
- `name` (String)
- `service_account` (String) ServiceAccount is the name of the service account this credential authenticates. It must exist in the same workspace (or, for a service account without a workspace, the same tenant) as this credential.

### Optional

- `annotations` (Map of String)
- `client_id` (String) ClientID is the fully-qualified, non-secret client identifier for a "Token" credential: tenant:service-account:credential (or tenant:workspace:service-account:credential). It is set when the credential is created so client tools have a canonical value to read; present it with the client secret to the token endpoint. Empty for "Federated" credentials.
- `expires_at` (String) ExpiresAt is the time at which this credential stops being accepted for authentication. If unset, the credential remains valid until it is deleted.

### Nested Schema for `federated`

Required:

- `issuer` (String) Issuer is the OIDC issuer that must have signed the presented token, matched exactly against the token's "iss" claim. It must be an https URL with no query or fragment; OIDC discovery is performed against it at exchange time.
- `subject` (String) Subject is matched against the token's "sub" claim. It is an exact match unless it ends with a single "*", which makes it a prefix match (for example "repo:acme/app:*"). The "*" is only valid as the final character and the prefix before it must be at least eight characters.

Optional:

- `audiences` (List of String) Audiences are the accepted values for the token's "aud" claim; at least one must match. When omitted it is defaulted at creation time to the canonical Wayfinder audience for the tenant, which is also the audience the workload must request.
- `claims` (Map of String) Claims are additional token claims that must all be present and exactly equal to the given values, for example pinning GitHub's rename-proof "repository_owner_id".
