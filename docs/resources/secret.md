# wayfinder_secret (Resource)

Manages one secret in Wayfinder's variable and secret hierarchy, at tenant, workspace or environment scope. The secret value is write-only: Terraform sends it to Wayfinder but never stores or reads it back, so changes made outside Terraform to the value are not detected; only the existence of the secret is.

Creating a secret whose key already exists at the same scope fails with an import hint instead of overwriting it. After `terraform import`, set `value_wo` and `value_wo_version` in configuration; the value is sent the next time `value_wo_version` changes.

Each `wayfinder_secret` manages a single key. Other keys at the same scope are left alone. Keys resolve through Wayfinder's variable and secret hierarchy, as for `wayfinder_variable`.

`value_wo` is write-only: it's sent to Wayfinder when the secret is created and whenever `value_wo_version` changes, and it's never stored in Terraform state or plan files. Feed it from an ephemeral variable or ephemeral resource so the value never touches state. Requires Terraform or OpenTofu 1.11 or later.

A key that already exists at the same scope must be imported before Terraform can manage it.

## Example Usage

```terraform
variable "db_password" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "wayfinder_secret" "db" {
  key       = "db_credentials"
  workspace = "plat"

  # Write-only: sent to Wayfinder, never stored in state.
  value_wo = jsonencode({ user = "app", password = var.db_password })

  # Change this to send a new value_wo.
  value_wo_version = "1"
}
```

## Schema

### Required

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `key` (String) Name of the key. Must start with a letter or underscore and contain only letters, digits, underscores and dashes. Changing it replaces the resource.
- `value_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Value of the secret as a JSON document, for example `value_wo = jsonencode(var.db_password)` or `value_wo = jsonencode({ user = "app", password = var.db_password })`. Write-only: it is never stored in Terraform state or plan, and Wayfinder never returns it. It is sent when the secret is created and whenever `value_wo_version` changes; changing only `value_wo` does not update the secret. Requires Terraform or OpenTofu 1.11 or later.

### Optional

- `environment` (String) Environment (within `workspace`) the key belongs to. Requires `workspace`. Omit for a workspace-wide key. Changing it replaces the resource.
- `value_wo_version` (String) Change this value to send a new `value_wo` to Wayfinder.
- `workspace` (String) Workspace the key belongs to. Omit for a tenant-wide key. Changing it replaces the resource.

### Read-Only

- `id` (String) Identifier `[workspace/[environment/]]key`, also used for import.

## Import

The import ID is `[workspace/[environment/]]key`. After importing, set `value_wo` and `value_wo_version`; the value is sent the next time `value_wo_version` changes.

```shell
#!/bin/sh
set -eu
# [workspace/[environment/]]key
terraform import wayfinder_secret.db 'plat/db_credentials'
```
