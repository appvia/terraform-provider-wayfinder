# wayfinder_role_binding (Resource)

RoleBinding grants one or more Wayfinder roles to a user, group or service account. How far the granted access reaches is decided by where the binding is created rather than by what it is: create it at system, tenant, workspace or environment level and the roles apply there. This one kind covers every scope, replacing the four scope-specific role-binding kinds that remain only for existing configuration.
