# wayfinder_aws_account (Resource)

AWSAccount is an AWS account your tenant works in. You add one for each account you operate, which is what tells Wayfinder the account exists before any credential for it does — so you can see and pick it while setting the rest up.

Its name is the AWS account ID, e.g. "123456789012", so an account is the same object however it is reached and a reference to it can never come to mean a different real account. Give it a display name to say what it is for.

It grants no access of its own: an external identity naming this account is what lets Wayfinder act in it. It records only facts about the account and never changes state, so it has no status.
