# wayfinder_environment (Resource)

Environment is a deployment stage within a workspace, e.g. dev, staging or production. Deployments are made into an environment, the variable and secret hierarchy can be given per-environment values, and access is granted per environment - so a team can be free to deploy into dev while production stays restricted.

  name = "example"
