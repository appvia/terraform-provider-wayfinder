# wayfinder_dns_zone (Resource)

DNSZone represents a hosted DNS zone for a domain in AWS Route 53, Azure DNS, or Google Cloud DNS. Wayfinder creates the zone in the cloud account you point it at, publishes its authoritative nameservers, and — where you name a parent zone that Wayfinder also manages — sets up and checks the delegation between the two. Clusters and applications draw their host names from the zone's entry templates, so deployments get working DNS without anyone editing records by hand. A zone can also be marked unmanaged, in which case Wayfinder only verifies it exists and uses it as a delegation parent.
