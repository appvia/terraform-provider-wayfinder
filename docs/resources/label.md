# wayfinder_label (Resource)

Label is one of the labels in use across a tenant. Its name is either a label key on its own, e.g. "team", or a key and value together separated by a colon, e.g. "team:platform". Labels appear automatically as soon as any resource is labelled, so you can list what is already in use; creating one explicitly lets you offer a key or value before anything carries it, and deleting one tidies a value that is no longer wanted. A key cannot be deleted while values still exist under it. Labels carry no configuration of their own beyond their name and metadata.
