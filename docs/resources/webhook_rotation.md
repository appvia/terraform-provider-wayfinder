# wayfinder_webhook_rotation (Resource)

Rotates a webhook's ingest URL. Creating this resource, or changing `webhook`, `workspace` or `triggers`, issues a new URL and immediately invalidates the previous one. The URL is never stored; read it with the `wayfinder_webhook_ingest_url` ephemeral resource using `name = wayfinder_webhook_rotation.<label>.name`. Destroying this resource leaves the current URL working. Requires the `webhooks/rotate` permission.

A webhook has no ingest URL until one is generated. This resource generates it, so there is no CLI step between creating the webhook and using its URL. Every rotation replaces the URL and invalidates the previous one immediately, so update the sender that posts to it in the same run.

## The URL is never stored

The ingest URL is a credential, so this resource doesn't keep it in state or plan files. Read it with the [`wayfinder_webhook_ingest_url`](../ephemeral-resources/webhook_ingest_url.md) ephemeral resource and pass `name = wayfinder_webhook_rotation.<label>.name`. That value isn't known until the rotation has run, so the ephemeral resource is read after it, in the same apply. The ephemeral resource needs Terraform 1.11 or later, or OpenTofu 1.11 or later.

To send the URL to a write-only attribute such as `value_wo` only when it changes, set the attribute's `*_wo_version` to `rotation_id`. It is a random value that changes on every rotation and tells you nothing about the URL.

## Rotating again

Changing `webhook`, `workspace` or `triggers` replaces the resource and issues a new URL. To rotate on a schedule, or on demand, put a value that changes into `triggers`, for example the ID of a `time_rotating` resource.

Changing the webhook's own settings with `wayfinder_webhook` doesn't change the URL.

## Importing and recreated webhooks

- Importing the resource doesn't rotate and leaves `triggers` unset. Adding `triggers` afterwards replaces the resource, so the URL is rotated on the next apply.
- If the webhook is recreated under the same name, the new webhook has no URL until this resource is replaced. Tie a trigger to a value that changes when the webhook is recreated, so the URL is generated again.

## Destroying

Destroy only removes the resource from state. It doesn't rotate the URL, and the current URL keeps working.

## Permissions

Rotating a webhook needs the `webhooks/rotate` permission, which is separate from permission to manage the webhook itself. Reading the URL needs the ingest-URL permission.

## Example Usage

```terraform
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: Apache-2.0

# Rotate the ingest URL of a webhook. Creating this resource issues the first
# URL, and any change to triggers issues a new one.
resource "wayfinder_webhook_rotation" "alerts" {
  webhook   = wayfinder_webhook.alerts.name
  workspace = "plat"

  # Rotate every 90 days. Without the time provider, use a fixed value such as
  # triggers = { rotation = "1" } and change it to rotate on demand.
  triggers = {
    rotation = time_rotating.alerts.id
  }
}

resource "time_rotating" "alerts" {
  rotation_days = 90
}

# The URL is read after the rotation, in the same apply, and never stored.
ephemeral "wayfinder_webhook_ingest_url" "alerts" {
  name      = wayfinder_webhook_rotation.alerts.name
  workspace = "plat"
}

# Keying value_wo_version on rotation_id sends the new URL exactly when it changes.
resource "wayfinder_secret" "alerts_ingest_url" {
  key              = "alerts_ingest_url"
  value_wo         = jsonencode(ephemeral.wayfinder_webhook_ingest_url.alerts.url)
  value_wo_version = wayfinder_webhook_rotation.alerts.rotation_id
}
```

## Schema

### Required

- `webhook` (String) Name of the webhook to rotate. Changing it rotates the newly named webhook.

### Optional

- `triggers` (Map of String) Arbitrary values that rotate the URL again whenever any of them change, for example `{ rotation = time_rotating.webhook.id }`.
- `workspace` (String) Workspace of the webhook. Omit for a tenant-scoped webhook.

### Read-Only

- `id` (String) `<webhook>` for a tenant-scoped webhook, or `<workspace>/<webhook>`.
- `name` (String) Webhook name, equal to `webhook`. Pass it to `wayfinder_webhook_ingest_url` so the URL is read only after this rotation.
- `rotated_at` (String) Time of the last rotation (RFC 3339, UTC). Informational only.
- `rotation_id` (String) Random value, unrelated to the URL, that changes on every rotation. Use it as the `*_wo_version` of write-only attributes that receive the URL.

## Import

The import ID is the webhook name, or `<workspace>/<webhook>` for a workspace webhook. Import doesn't rotate the URL.

```shell
#!/bin/sh
# Copyright 2026 Appvia Ltd.
# SPDX-License-Identifier: Apache-2.0

set -eu
# <webhook> for a tenant webhook, <workspace>/<webhook> for a workspace webhook.
terraform import wayfinder_webhook_rotation.tenant_hook 'alerts'
terraform import wayfinder_webhook_rotation.alerts 'plat/alerts'
```
