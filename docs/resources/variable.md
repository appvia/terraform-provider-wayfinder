# wayfinder_variable (Resource)

Manages one variable in Wayfinder's variable and secret hierarchy, at tenant, workspace or environment scope. Variable values are not secret and are stored in Terraform state; use `wayfinder_secret` for sensitive values.

Creating a variable whose key already exists at the same scope fails with an import hint instead of overwriting it.

Each `wayfinder_variable` manages a single key. Other keys at the same scope, including ones set in the Wayfinder UI or by other configurations, are left alone. The value is a JSON document, so use `jsonencode` for strings, numbers, lists and objects.

Keys resolve through Wayfinder's variable and secret hierarchy: an environment value overrides a workspace value, which overrides a tenant value.

Creating a variable whose key already exists at the same scope fails with an import hint rather than overwriting it. Import the existing key first.

## Example Usage

```terraform
# Tenant-wide variable.
resource "wayfinder_variable" "region" {
  key   = "default_region"
  value = jsonencode("eu-west-2")
}

# Variable scoped to one environment of a workspace.
resource "wayfinder_variable" "replicas" {
  key         = "replicas"
  workspace   = "plat"
  environment = "dev"
  value       = jsonencode(2)
}
```

## Schema

### Required

- `key` (String) Name of the key. Must start with a letter or underscore and contain only letters, digits, underscores and dashes. Changing it replaces the resource.
- `value` (String) Value of the variable as a JSON document; any JSON value is allowed. Use `jsonencode`, for example `value = jsonencode("eu-west-2")` for a string or `value = jsonencode({ replicas = 3 })` for an object.

### Optional

- `environment` (String) Environment (within `workspace`) the key belongs to. Requires `workspace`. Omit for a workspace-wide key. Changing it replaces the resource.
- `workspace` (String) Workspace the key belongs to. Omit for a tenant-wide key. Changing it replaces the resource.

### Read-Only

- `id` (String) Identifier `[workspace/[environment/]]key`, also used for import.

## Import

The import ID is `[workspace/[environment/]]key`.

```shell
#!/bin/sh
set -eu
# [workspace/[environment/]]key
terraform import wayfinder_variable.region 'default_region'
terraform import wayfinder_variable.replicas 'plat/dev/replicas'
```
