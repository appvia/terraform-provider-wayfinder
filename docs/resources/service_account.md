# wayfinder_service_account (Resource)

ServiceAccount is a non-human account for automating Wayfinder from CI pipelines, scripts and other external systems. A service account can be granted roles in the same way as a user, and authenticates using one or more credentials, each represented by a ServiceAccountCredential. A service account created without a workspace can be granted access across the whole tenant; one created within a workspace can only be used within that workspace.
