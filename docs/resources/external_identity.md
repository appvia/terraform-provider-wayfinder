# wayfinder_external_identity (Resource)

ExternalIdentity represents credentials or configuration that grant Wayfinder access to an external system: a cloud account (an AWS account, Azure subscription, or GCP project), a source control provider, a container registry, or any other endpoint Wayfinder must authenticate to on your behalf. The type field selects what kind of access this is and, for cloud types, which cloud it reaches; the matching sub-block carries the identity's configuration and any secret material.

Optional:

- `can_grant` (Boolean) CanGrant lets this grantee change who may use this identity and what it is for — editing spec.usableBy and spec.usableFor. - `role` (Attributes) Role grants use to any subject holding a Wayfinder role at a scope, evaluated from the roles the caller holds at the time of the request. Its scope fields are read relative to where the identity itself lives: workspace is pinned for a workspace-scoped identity, both are pinned for an environment-scoped one, and a tenant-scoped identity must state one or the other. Leaving it empty grants every verb in spec.usableFor, and keeps following that list as it changes — it does NOT confer nothing.
