# wayfinder_cloud_resource (Resource)

CloudResource is a single deployment of a CloudResourcePlan into a cloud account, provisioned with Terraform/OpenTofu from the plan's template and the inputs given here. It may be infrastructure — a database, a storage bucket, a network — or an application workload running on a managed cloud runtime such as Cloud Run, Lambda or Azure Container Apps.

Its status carries what the deployment produced: the outputs applications consume, the workload identity they use to reach it, the permissions that identity can be granted, and where its Terraform/OpenTofu state is kept. Create one directly, or let a stack instance create it as part of deploying an application.

## Example Usage

```terraform
// Code generated by tfgen. DO NOT EDIT.
resource "wayfinder_cloud_resource" "example" {
  name = "example"
  workspace = "example"
  environment = "example"
  cloud = "aws"
  plan_ref = "example"
}
```
