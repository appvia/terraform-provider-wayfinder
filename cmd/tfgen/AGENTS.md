# cmd/tfgen

## OVERVIEW
Manifest → Go schema code (`internal/generated/zz_*.go`), generated examples, plan-stability cases, and `-diff` schema-change reports. Invoked by `//go:generate` in `internal/generated/doc.go`.

## WHERE TO LOOK
| Task | File | Notes |
|------|------|-------|
| Entry, flags (`-manifest`, `-out`, `-examples`, `-diff`) | main.go | Paths resolve from repo root |
| Per-kind output, registry, ctor glue | render.go | `render()`; `header` const = generated marker |
| Attribute naming, class, plan modifiers, `_wo` pairs | attributes.go | `fieldName`, `attributeClass`, `firstSecret` |
| Schema body emission, semver validator | schema.go | |

| Bump summary (`BREAKING` first line) | diff.go | Used by `scripts/bump-wayfinder.sh` |

## CONVENTIONS
- Every kind is compiled with `convert.NewMapping` first; a mapping error aborts generation, so tfgen and the runtime engine can never disagree on shape.
- Output only for `m.TypedKinds()`, sorted by Terraform type name; duplicate type names fail.
- Stale-file cleanup deletes only files starting with the Go header or `#!/bin/sh\n# Code generated by tfgen. DO NOT EDIT.` — hand-written examples survive.
- New upstream wording that trips `forbiddenWording` → add a narrow, commented rule to `wordingRules` plus a test. Don't widen the forbidden regex to dodge it.
- Golden tests use `internal/manifest/testdata/golden-manifest.json` → `testdata/`; refresh with `go test ./cmd/tfgen -update` and review the diff.
- `testdata/diff/*.json` are paired manifests for `diff_test.go` (added kind, removed attribute, type change, newly required).

## ANTI-PATTERNS
- Emitting a plain `Sensitive` attribute for an unmappable `+encrypted` field (below computed/write-only container, secret object, secret collection element) — return an error.
- Editing generated output to fix a schema bug; fix the emitter and regenerate.
- Changing output ordering/formatting nondeterministically — `make check-reproducible` and CI `git diff --exit-code` will fail.
