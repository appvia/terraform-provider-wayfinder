## OVERVIEW
Terraform/OpenTofu provider for Appvia Wayfinder (terraform-plugin-framework, protocol v6, Go). ~36 typed resources + data sources are **generated** from a manifest reflected out of a pinned private Wayfinder release; `wayfinder_manifest`, `wayfinder_variable`, `wayfinder_secret` are hand-written. Deep process docs: [DEVELOPMENT.md](DEVELOPMENT.md), [RELEASING.md](RELEASING.md).

## STRUCTURE
```
.
├── WAYFINDER_REF            # pinned Wayfinder tag (one line); bump via make bump-wayfinder
├── schema/                  # wayfinder-manifest.json (GENERATED) + go:embed into binary
├── tools/manifestgen/       # manifest generator; runs INSIDE .wayfinder-src only (see its AGENTS.md)
├── cmd/tfgen/               # manifest → internal/generated + examples + schema diff (see its AGENTS.md)
├── internal/
│   ├── manifest/            # manifest contract types; stdlib-only (copied into Wayfinder checkout)
│   ├── generated/           # zz_*.go GENERATED; manifest.go, *_test.go harnesses hand-written
│   ├── engine/              # generic CRUD/wait/import for every typed kind (see its AGENTS.md)
│   ├── convert/             # tftypes.Value ⇄ Wayfinder JSON via compiled per-kind Mapping
│   ├── manifestresource/    # wayfinder_manifest (any kind incl. manifest-only, YAML/JSON)
│   ├── vars/                # wayfinder_variable / wayfinder_secret (+ variable data source)
│   ├── client/              # HTTP client, Ref, sentinel errors (ErrNotFound, ErrModified)
│   ├── auth/                # token / federated (GitHub OIDC) / client-credentials
│   ├── provider/            # provider block, Configure, registration
│   ├── fakeapi/             # in-process fake Wayfinder API for unit tests
│   └── acctest/             # TF_ACC acceptance tests + sweepers vs real backend
├── templates/               # tfplugindocs templates (edit these, not docs/)
├── examples/                # mostly GENERATED; provider/, manifest, variable, secret hand-written
├── docs/                    # GENERATED by make docs; never hand-edit
├── scripts/                 # checkout, manifestgen, bump, reproducibility, guards (+ shell tests)
└── .wayfinder-src/          # disposable gitignored Wayfinder checkout; ignore when searching
```

Generated code = thin glue: schemas are static Go, but each resource still resolves its `manifest.Kind` from the **embedded** JSON. Schema JSON and `zz_*.go` must match → always regenerate together.

## CONVENTIONS
- Generated files start `// Code generated by tfgen. DO NOT EDIT.`; tfgen deletes stale files only if they carry that header.
- Test names: `TestThing_whenCondition` (e.g. `TestNestedRead_whenOptionalChildNotConfigured`).
- Optimistic concurrency: `metadata.generation` stored in resource **private state** key `"generation"`; mismatch → `client.ErrModified`.
- Secrets: `+encrypted` → `<field>_wo` + `<field>_wo_version` pair; data sources omit secrets entirely.
- Provider descriptions/docs target SaaS users (no "your administrator", "this instance", Helm values, `WF_*`).
- Examples use `yamlencode(...)`/`jsonencode(...)`, not heredocs.
- Commits: Conventional Commits with package scope (`fix(engine): …`, `feat(generate): …`).
- Lint: golangci v2 — errcheck, govet, ineffassign, staticcheck, unused, misspell, unconvert; gofmt + goimports.

## ANTI-PATTERNS (THIS PROJECT)
- Hand-editing `schema/wayfinder-manifest.json`, `internal/generated/zz_*`, `docs/`, generated `examples/`. CI diffs all of them.
- Non-stdlib imports in `internal/manifest/contract.go` (`TestContractImportsAreStdlib`).
- Any dependency on the private `github.com/appvia/wayfinder` module from the root module (`scripts/check-no-private-deps.sh`).
- Committing anything from `.wayfinder-src/`; `go mod tidy` or building in `tools/manifestgen/`.
- Putting secret values in state/plan (Read never sets `_wo`; secretleak tests guard this).
- Downgrading an unmappable secret to a plain sensitive attribute — tfgen must fail instead.

## COMMANDS
```bash
make build                     # ./terraform-provider-wayfinder (VERSION=dev)
make test                      # go test ./... -count=1 (fakeapi; no backend)
make lint
make generate                  # go generate ./... → cmd/tfgen
make docs                      # needs terraform >=1.11 on PATH
go test ./cmd/tfgen -update    # refresh tfgen golden testdata
go test -tags secretleakcheck ./internal/generated   # opt-in secret leak suite
make testacc                   # TF_ACC=1; needs WAYFINDER_SERVER + TOKEN(+TENANT) or CLIENT_ID/SECRET
go test ./internal/acctest/... -sweep=ci            # clean up tfacc-* objects
# Need private Wayfinder access:
make wayfinder-src | make manifest [MANIFEST_OUT=/tmp/m.json] | make manifestgen-test
make bump-wayfinder REF=vX.Y.Z [BUMP_ARGS=--dry-run]
make check-reproducible        # clean-room regen; must leave zero diff
make test-scripts              # shell scenario tests for scripts/
```

## NOTES
- Terraform/OpenTofu ≥ 1.11 required (write-only attributes).
- `internal/generated` tests clear all `WAYFINDER_*`/`ACTIONS_ID_TOKEN_*` env in `TestMain` so cases run `t.Parallel()`; don't use `t.Setenv` there.
- `zz_resources_test.go` is generated: one plan-stability case per typed kind; a kind with no synthesizable fixture gets `Skip`.
- Acceptance objects must be named with `acctest.NamePrefix` (`tfacc-`) or sweepers miss them.
- CI: `test.yml` (test, lint, generate drift, private-deps, docs drift) for everyone; `manifest.yml` regen only with secrets (no forks/Dependabot); nightly `acceptance.yml`, daily `bump-wayfinder.yml`.
- `dist/` and the root binary are build output; ignore.
